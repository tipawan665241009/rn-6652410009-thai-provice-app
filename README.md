## Features

- **Discover Places**: Explore top attractions, temples, and natural sites.
- **Interactive Maps**: View locations on an integrated map.
- **Weather Information**: Real-time weather updates for your travel planning.
- **Premium UI**: Modern design with glassmorphism effects and smooth transitions.

## Tech Stack

- **Framework**: Expo / React Native
- **Language**: TypeScript
- **Backend**: Supabase
- **Icons**: @expo/vector-icons
- **Maps**: react-native-maps

## Get Started

1. **Install dependencies**
   ```bash
   npm install
   ```

2. **Start the app**
   ```bash
   npx expo start
   ```
